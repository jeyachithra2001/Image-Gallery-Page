# 📸 Gallery Website

A responsive and interactive **Gallery Website** designed to showcase beautiful images in an attractive card-based layout. The project includes **search, category filtering functionalities** to provide a better user experience.

## Live Demo

View Live Website: (https://image-gallery-page-ruby.vercel.app/)

## 🌟 Features

* 🏠 **Home & Gallery Navigation**
* 🖼️ **Responsive Image Gallery**
* 🔍 **Search Functionality**
  * Search images by title.

* 🏷️ **Category Filter**
  * Filter images based on categories such as:
    * All
    * Nature
    * Travel
    * City
    * Animals
    * Flowers

* ❤️ **Wishlist Functionality**
* 📱 **Responsive Design**
  * Desktop, tablet, and mobile-friendly layouts.

* 🎨 **Modern UI**
  * Clean cards, rounded corners, gradients, icons, and responsive layouts.

## 🖥️ Technologies Used

* **Vite**

## ⚙️ Functionalities

### 🔍 Search

Users can search for gallery items using the search field. The displayed cards are dynamically filtered based on the entered search text.

### 🏷️ Category Filter

Users can select a category to display only the relevant images.

Example:

```text
All | Nature | Travel | City | Animals | Flowers
```

## 📱 Responsive Design

The website is designed to work across different screen sizes:

* 💻 Desktop – 3-column gallery
* 📱 Tablet – 2-column gallery
* 📱 Mobile – 1-column gallery
